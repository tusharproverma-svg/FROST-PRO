FROST-PRO V45 — SELF-UPGRADE ENGINE
====================================

V45 is additive based on V44. Existing app files remain, and a separate `self-upgrade-engine/` module has been added.

Included:
1. Request interpreter for a limited set of visual changes.
2. Plan/spec generator for feature requests.
3. Allowlist validator for selected UI settings.
4. Isolated separate page to test and export plan JSON.
5. Launcher section in the main app.
6. Documentation explaining limitations and safe next steps.

Important:
- This is a prototype, not a full autonomous AI coder.
- Feature ideas such as “add a Coding Studio” are captured as a spec, not implemented as working code.
- No API key is included and no AI model is connected.
- No generated code is executed.
- No APK build/signing or GitHub push/deploy occurs.
- ZIP integrity and important old/new code markers were checked; no end-to-end Android test was performed.
- Keep a backup and test in a separate branch before deploying.
