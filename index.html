Safety boundary

  • It does not run generated code or use eval.
  • New feature requests become specs/backlog items; they are not implemented automatically.
  • Only a small list of styling settings can be applied locally.
  • For true autonomous coding, add a trusted AI backend, isolated test/build environment, backups, diff review and explicit approval.
